# Corporate Design der THM

## 1. Farben

Verwende ausschließlich die offiziellen Farben der Technischen Hochschule Mittelhessen:

| Farbe | Hex-Wert | RGB | Rolle |
|---|---|---|---|
| THM Grün | #80BA24 | 128, 186, 36 | Hauptfarbe |
| THM Grau | #4A5C66 | 74, 92, 102 | Hauptfarbe |
| THM Rot | #9C132E | 156, 19, 46 | Sekundärfarbe |
| THM Gelb | #F4AA00 | 244, 170, 0 | Sekundärfarbe |
| THM Hellblau | #00B8E4 | 0, 184, 228 | Sekundärfarbe |
| THM Blau | #002878 | 0, 40, 120 | Sekundärfarbe |

## 2. Verwendung der Farben

- THM Grün und THM Grau sind die Hauptfarben.
- THM Grau wird für Fließtext verwendet.
- THM Grün wird für Akzente und Gestaltungselemente verwendet.
- Die Sekundärfarben dienen zur Hervorhebung wichtiger Informationen und für Infografiken.
- Verwende Weiß als Hintergrundfarbe.

## 3. Lesbarkeit

- Fließtext auf weißem Hintergrund muss einen ausreichenden Kontrast besitzen.
- THM Grau eignet sich für Fließtext auf Weiß.
- THM Grün darf wegen seines geringen Kontrasts nicht für Fließtext auf Weiß verwendet werden.

## 4. Gestaltungsregeln

- Verwende ausschließlich die festgelegten THM-Farben und Weiß.
- Definiere die Farben zentral in CSS-Variablen unter :root.
- Verwende keine zusätzlichen Farben.
- Verwende keine Farbverläufe.
- Verwende keine unnötigen Schatten.
- Achte auf ein übersichtliches und einheitliches Design.
